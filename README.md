## Project Structure

This repository contains the following core components:

- **[The-Greggory-Systems-And-Strategy-firm website/](The-Greggory-Systems-And-Strategy-firm%20website/)**: The main web platform, featuring:
  - **Client Portal**: Transparent, live project tracking for our partners.
  - **Mission Control (Admin Dashboard)**: A high-density telemetry center for asset deployment and tracking.
  - **Hardened API Relay**: A secure backend integration for real-time synchronization.
- **Automation & Branding Scripts**: Custom Python scripts (`update_brand.py`, `replace_company_name.py`) for maintaining system-wide brand consistency.

## Technologies

- **Frontend**: React + Vite, Tailwind CSS (Glassmorphism), Lucide Icons.
- **Backend**: Node.js, Express.js, JWT Authentication.
- **Database**: MySQL (Primary), MongoDB (Dual-write for Strategic Standard).
- **Communication**: Integrated SMS and WhatsApp messaging relays.
